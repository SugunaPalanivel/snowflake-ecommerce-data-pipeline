# Snowflake E-Commerce Data Pipeline

## Goal
Build an end-to-end, production-style ELT pipeline using Snowflake, Python, dbt, and Apache Airflow.

## Planned architecture
Source data (CSV/JSON/API)
→ Snowflake stage
→ RAW layer
→ STAGING layer
→ ANALYTICS layer
→ dbt tests and documentation
→ Airflow orchestration

## Technologies
- Snowflake
- SQL
- Python
- dbt
- Apache Airflow
- GitHub Actions
- Terraform
